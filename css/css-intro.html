Урок 1: Вступ до CSS та способи підключення

CSS (Cascading Style Sheets) — це каскадні таблиці стилів. CSS відповідає за зовнішній вигляд сторінки: кольори, шрифти, відступи, розміри та розміщення елементів.

Синтаксис CSS

CSS-правило складається з селектора та блоку оголошень (властивість: значення):

Приклад CSS коду

body {
    background-color: #f8f9fa;
    color: #333333;
}

h1 {
    color: #10b981;
    font-size: 24px;
}
Спробувати в редакторі »

Як підключити CSS до HTML:

1. Зовнішні стилі (External): Підключення окремого файла через <link rel="stylesheet" href="style.css"> у тегу <head> (найкращий спосіб).

2. Внутрішні стилі (Internal): Написання стилів усередині тегу <style> прямо в HTML-документі.

3. Вбудовані стилі (Inline): Написання стилів безпосередньо в атрибуті тегу style="...".
