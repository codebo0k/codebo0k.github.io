Урок 1: Вступ до JavaScript

JavaScript (JS) — це мова програмування, яка робить веб-сторінки інтерактивними та «живими». Вона дозволяє обробляти кліки, робити анімації, надсилати дані без перезавантаження сторінки та створювати динамічні елементи.

Перший скрипт та console.log()

Команда console.log() використовується для виведення інформації в консоль розробника у браузері:

Приклад JS коду

// Виведення повідомлення в консоль
console.log("Привіт з JavaScript!");

// Просте сповіщення на екрані
alert("Вітаємо на CodeBook.ua!");
Спробувати в редакторі »

Як підключити JavaScript до сторінки:

Скрипти підключаються за допомогою тегу <script>. Зазвичай їх ставлять перед закриваючим тегом </body>:

1. Окремий файл: <script src="script.js"></script>

2. Прямо в коді: <script> console.log('Hello'); </script>
