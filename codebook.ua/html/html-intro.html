Урок 1: Вступ до HTML та структура документа

HTML (HyperText Markup Language) — це мова гіпертекстової розмітки, яка є основою кожного веб-сайту. Вона відповідає за вміст та структуру сторінки: текст, кнопки, зображення та посилання.

Базова структура HTML5

Кожен HTML-документ складається з базового каркаса:

Приклад структури

<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Моя перша сторінка</title>
</head>
<body>

    <h1>Привіт, світ!</h1>
    <p>Це мій перший веб-сайт на HTML.</p>

</body>
</html>
Спробувати в редакторі »

Основні теги:

1. <!DOCTYPE html> — повідомляє браузеру, що версія документа — HTML5.

2. <html> — головний тег, у який загортається увесь код сторінки.

3. <head> — містить мета-дані (назву сторінки, кодування, підключення стилів).

4. <body> — містить увесь контент, який бачить відвідувач сайту.
